## Brand & Style
This design system expresses a high-precision, dark editorial aesthetic tailored for an emerging engineering and IT academic portfolio. It merges the disciplined restraint of Swiss editorial design with the luminous tactility of an integrated development environment (IDE). The visual tone commands respect without arrogance—communicating intellectual rigor, technical aptitude, focus, and quiet confidence.

The design movement combines **Minimalism** with subtle **Glassmorphic Surface Shading** and **Architectural Wireframe Precision**:
- **Deep Obsidian Immersion:** True dark-mode foundations that allow subtle tonal planes and glowing accent nodes to communicate structure.
- **Editorial Contrast Hierarchy:** Heavyweight, high-tracking geometric display titles paired against balanced humanist sans-serif body typography.
- **Instrument-grade Line Work:** Ultra-fine 1px hairline tracks, target rings, and vertical guide rules reminiscent of engineering schematics, oscilloscope plots, and precision instrumentation.
- **Laser-focused Electric Blue:** A vibrant, single-point blue accent reserved for interaction states, active milestones, and focal anchors.

## Colors
The palette is built on strict chromatic discipline, prioritizing luminous contrast over decorative saturation.

### Role Mapping
- **Canvas Base (`#111315`):** Deep obsidian backdrop anchoring full-viewport frames and establishing a low-light gallery environment.
- **Card & Base Surface (`#181B1E`):** Low-contrast structural containers and section plates providing slight foreground separation.
- **Elevated Interactive Plane (`#22262B`):** Hover states, timeline nodes, and recessed pill backgrounds.
- **Electric Accent (`#2D8CFF`):** High-energy primary anchor used intentionally for active navigation markers, interactive nodes, hover glows, and progress indices.
- **Text & Stroke Spectrum:**
  - `ink-primary` (`#FFFFFF`): 100% white reserved for primary headlines, badge monograms, and key stats.
  - `ink-soft` (`rgba(255, 255, 255, 0.68)`): Body copy, explanatory meta text, and secondary subtitles.
  - `ink-dim` (`rgba(255, 255, 255, 0.35)`): Metric guide rules, structural dividers, inactive tracks, and copyright metadata.
  - `glow-focus` (`rgba(45, 140, 255, 0.25)`): Subtle drop aura for active states and focused interactive targets.

## Typography
Typography creates an editorial dual-register: authoritative, geometric display forms paired with highly legible, modern humanist UI prose.

### Rules & Styling Guidelines
- **All Display & Column Titles:** Set in **Montserrat**, rendered in all caps (`text-transform: uppercase`), with expanded tracking (`0.08em` to `0.20em`).
- **Hero Staggering:** The display name uses an asymmetrical weight shift—first name in Light (300) with wide tracking (`0.14em`), contrasted directly against the surname in Black (900) with tight geometric punch (`0.04em`).
- **Prose & Data Elements:** Set in **Plus Jakarta Sans**. Body text uses open line heights (`1.8`) with bounded widths (max `52ch`) to ensure effortless reading over dark surfaces.
- **Code Badges & Micro Labels:** Rendered in semi-bold weights with uppercase rendering to preserve geometric symmetry inside compact containers.

## Layout & Spacing
The layout follows an editorial structured grid with generous dynamic whitespace, framing content as technical museum exhibits.

### Grid & Breakpoints
- **Canvas Base:** Full-bleed fluid presentation bounded by dynamic viewport horizontal gutters (`8vw` on desktop, tapering to `6vw` on tablet and `1.25rem` on mobile).
- **Desktop (≥ 1025px):**
  - **About:** Asymmetrical 2-column layout (1.1fr narrative copy | 0.9fr portrait artwork).
  - **Resume:** Balanced 3-column modular grid (1fr Core Skills & Languages | 1.15fr Chronological Timeline | 1fr Focus Areas & Interests) linked by `3rem` gutters.
- **Tablet (769px – 1024px):**
  - Columns collapse to a 2-column matrix with content wrapping logically; gutters adjust to `2rem`.
- **Mobile (≤ 768px):**
  - Strict 1-column stack. Section padding scales to vertical blocks of `80px` top and `48px` bottom. All horizontal margins reset to `1.25rem`.

### Vertical Cadence
- Desktop sections maintain `min-height: 100svh` where appropriate, using centered flex alignment to emulate full-screen editorial spreads.
- Internal component gap rhythm relies strictly on `space-sm` (8px), `space-md` (16px), and `space-xl` (40px) to prevent vertical density drift.

## Elevation & Depth
Depth is created through luminance layering, edge definition, and soft atmospheric backdrops rather than physical drop shadows.

### Depth Architecture
1. **Base Plane (Floor):** `#111315` matte obsidian base.
2. **Backdrop Atmosphere:** Radial and linear gradient overlays coupled with low-opacity (10%) contextual workspace photography.
3. **Glass Layer (Navigation):** Fixed header uses `rgba(17, 19, 21, 0.75)` surface with `backdrop-filter: blur(10px)` and a bottom hairline divider (`1px solid rgba(255, 255, 255, 0.08)`).
4. **Structural Containers:** Surfaces use `#181B1E` framed by `1px solid rgba(255, 255, 255, 0.12)`.
5. **Interactive Glows:** Primary active elements emit a calibrated, soft electric aura (`box-shadow: 0 0 16px rgba(45, 140, 255, 0.25)`), evoking luminescent indicators on hardware modules.

## Shapes
The shape language is deliberately hybrid: expansive **Pill-shaped (Level 3)** geometry for user actions and badges, contrasting with **Precision Orthogonal Geometry** for structural data grids and technical markers.

- **Buttons & Chips:** Full circular radiuses (`999px` / pill) produce welcoming touchpoints and streamline interactive flow.
- **Technical Badges:** Square `24x24px` containers with minimal `2px` corners or strict `0px` sharp edges to evoke hardware chipsets.
- **Milestone Nodes & Interest Rings:** Pure circular silhouettes (`border-radius: 50%`) ranging from `10px` target rings to `44px` icon containers.
- **Portraits & Media:** Masked with soft radial alpha gradients to dissolve seamlessly into `#111315` without abrupt rectangular edges.

## Components

### Buttons (Pill CTA)
- **Geometry:** Inline-flex, height 40px, padding `10px 28px`, border radius `999px`.
- **Default State:** Transparent fill, `1px solid rgba(255, 255, 255, 0.60)`, text color `ink-primary`, font size `13px`, tracking `0.05em`.
- **Hover/Focus State:** Background shifts to `#2D8CFF`, border color matches `#2D8CFF`, box shadow `0 0 16px rgba(45, 140, 255, 0.35)`, text `#FFFFFF`. Transition duration `0.3s cubic-bezier(0.25, 0.8, 0.25, 1)`.

### Technical Skill Indicators (2-Letter Code Badges & Percentage Tracks)
- **Monogram Chip:** `24x24px` square container, `1px solid rgba(255, 255, 255, 0.68)`, centered 2-letter uppercase monogram (`11px`, weight 600).
- **Metric Track:** Hairline horizontal line (`1px solid rgba(255, 255, 255, 0.15)`), flex-grow width.
- **Target Ring Node:** `10px` circular ring placed along the track at the percentage value:
  - Outer ring: `10px` circle with `1px solid #2D8CFF`.
  - Center pip: `3px` solid dot filled with `#2D8CFF`.

### Chronological Timeline
- **Spine:** `1px solid rgba(255, 255, 255, 0.35)` continuous vertical rule running along the node centerlines.
- **Active Node:** `44px` circular badge filled with `#2D8CFF`, holding bold white date range typography (`11px`, weight 700). Emits ambient glow.
- **Future / Milestone Node:** `44px` circular badge filled with `#22262B`, bordered with `1px solid #2D8CFF`, labeled in white.
- **Text Block:** High-contrast uppercase title (`13px`, weight 800) followed by secondary organizational context (`ink-soft`, 13px).

### Interest & Capability Tiles
- **Container:** `44px` circular outlined icon plate (`1px solid rgba(255, 255, 255, 0.68)`), centered SVG icon rendered in 18px monochrome white.
- **Hover State:** Border transitions to `#2D8CFF`, icon tint glows with blue accent.
- **Label:** Centered below icon, `11px`, weight 500, `rgba(255, 255, 255, 0.68)`.

### Navigation Bar
- **Dimensions:** Fixed top, height `76px`, padding `0 6vw`.
- **Material:** `rgba(17, 19, 21, 0.75)` backdrop blur (`10px`), bottom border `1px solid rgba(255, 255, 255, 0.08)`.
- **Navigation Links:** Horizontal flex row with `2rem` spacing. Inactive links `rgba(255, 255, 255, 0.68)`. Active state marked by `#2D8CFF` color and subtle bottom dot indicator.
